# NIGHTLINK 聊天室：Tailscale 使用說明書
<!-- 使用文件：主機啟動、朋友連線與 Tailscale 使用步驟。 -->

本文件供主機管理者與收到客戶端的朋友使用。不需要學會 C++ 才能聊天。

## 1. 你需要準備什麼？

| 角色 | 需要的東西 |
|---|---|
| 主機管理者 | Windows x64 電腦、Tailscale、`nightlink-server.zip`，以及可保持運作的網路與電源 |
| 聊天使用者 | Windows x64 電腦、Tailscale、`nightlink-client.zip`、主機分享邀請及主機的 Tailscale IPv4 |

本次打包使用 MinGW UCRT64。一般 Windows 10/11 x64 為預期使用環境；仍需在接收者電腦完成第 7 節驗收。macOS、Linux、手機不能直接執行這個 Win32 客戶端。

**每位使用者都需要安裝並登入 Tailscale。** 聊天室帳號欄只填暱稱，與 Tailscale 登入是兩件不同的事情。

```text
朋友的 GUI → Tailscale 私人網路 → 主機 chat_server.exe
你的 GUI   → Tailscale 私人網路 → 同一份 chat_server.exe
```

一般情況不必設定家中路由器 port forwarding，也不需要 Tailscale exit node、Serve 或 Funnel。本程式使用 TCP 9000，自行透過私人位址連線；網路無法直連時 Tailscale 可能使用中繼，仍可傳文字及圖片，但延遲可能不同。[Tailscale 防火牆與連線說明](https://tailscale.com/docs/reference/faq/firewall-ports)

## 2. 主機管理者：首次設定

### 步驟 A：確認 Tailscale 在線

1. 從 [Tailscale Windows 官方安裝頁](https://tailscale.com/docs/install/windows) 安裝並登入。
2. 開啟 PowerShell，執行：

   ```powershell
   & "$env:ProgramFiles\Tailscale\tailscale.exe" status
   & "$env:ProgramFiles\Tailscale\tailscale.exe" ip -4 
   ip = 100.73.138.15
   ```

3. 第二行會顯示主機的 Tailscale IPv4，通常是 `100.x.x.x`。記下**你實際取得的數字**。
4. 在系統匣 Tailscale 選單確認主機允許傳入連線（Allow incoming connections）。這仍受網路存取政策約束。[官方設定說明](https://tailscale.com/docs/features/client/manage-preferences?tab=windows)

`127.0.0.1` 只代表使用者自己的電腦；`0.0.0.0` 不是要發給朋友填入的地址。客戶端目前只支援數字 IPv4，請勿填網址、`http://`、IPv6 或 MagicDNS 主機名稱。

### 步驟 B：讓朋友取得這台主機的存取資格

建議分享這一台 server 裝置，讓朋友使用自己的 Tailscale 帳號：

1. 在主機管理者的 [Tailscale 管理頁](https://login.tailscale.com/admin/machines) 找到執行 server 的裝置。
2. 使用裝置的 Share／分享功能建立邀請。
3. 由你把邀請連結交給預定使用者。
4. 朋友用自己的帳號接受邀請，並在他的 Windows 電腦登入該帳號。
5. 確認朋友的 Tailscale 可看見／存取共享主機。

不必把你的帳號密碼交給朋友。如果兩台裝置本來就在同一 tailnet，則依該網路的存取政策互通，不必再做外部分享。[Tailscale 裝置分享文件](https://tailscale.com/docs/features/sharing)

**分享裝置不等於自動只開放聊天室。** 實際可存取服務由 tailnet 的 ACL／grants 與主機設定共同決定。如需限制朋友只能連 TCP 9000，請在管理頁設定相應存取政策，並檢查是否有其他較寬的允許規則；不要直接覆蓋整份現有政策。撤銷分享可取消外部朋友透過該分享取得的資格。

### 步驟 C：解壓縮並啟動 server

把 `nightlink-server.zip` 完整解壓縮到你自己的可寫資料夾。不要只拖出 exe；旁邊 DLL 也必須保留。

```text
nightlink-server/
  chat_server.exe
  start-server.cmd
  start-server.ps1
  libgcc_s_seh-1.dll
  libstdc++-6.dll
  libwinpthread-1.dll
  說明書.md
  SHA256SUMS.txt
  licenses/
```

雙擊 `start-server.cmd`。啟動腳本會取得**這台電腦自己的** Tailscale IPv4，將 server 綁定該位址與 TCP 9000，並顯示要交給朋友的資訊。

此腳本不需要把 Tailscale IP 寫死；它也不會自動修改防火牆或分享權限。`start-server.ps1` 設計為與 `chat_server.exe` 放在同一資料夾，請使用已打包的版本啟動。

視窗應顯示類似：

```text
Chat server address: 100.x.x.x  TCP port: 9000
Keep this window open. Type /quit to stop.
```

這裡的 `100.x.x.x` 是示意；實際執行會顯示完整數字。請保持視窗開啟，電腦不要睡眠。結束時輸入 `/quit` 後按 Enter。

若不用啟動腳本，也可在 server 所在資料夾手動執行：

```powershell
$serverIp = (& "$env:ProgramFiles\Tailscale\tailscale.exe" ip -4 | Select-Object -First 1).Trim()
.\chat_server.exe 9000 $serverIp
```

**不要直接雙擊 `chat_server.exe` 期待遠端能連入。** 沒帶參數時，它預設只監聽 `127.0.0.1`。

主機管理者也想聊天時，需要再開自己的 GUI，填同一個 Tailscale IP。server 的 console 是管理用，並不是聊天輸入區。

### 步驟 D：僅在連線受阻時檢查防火牆

先確認 server 正在運作、主機有允許傳入連線、朋友已接受分享，以及 Tailscale 政策允許 TCP 9000。

若仍被 Windows 防火牆擋住，可在 **server 資料夾**開啟系統管理員 PowerShell，新增限定程式、位址及 port 的規則：

```powershell
$serverIp = (& "$env:ProgramFiles\Tailscale\tailscale.exe" ip -4 | Select-Object -First 1).Trim()
$serverExe = (Resolve-Path .\chat_server.exe).Path
New-NetFirewallRule -DisplayName 'NIGHTLINK Tailscale TCP 9000' `
  -Direction Inbound -Action Allow -Protocol TCP -LocalPort 9000 `
  -LocalAddress $serverIp -RemoteAddress '100.64.0.0/10' `
  -Program $serverExe -Profile Any
```

不要重複建立相同規則，也不用關閉整個防火牆。若移動 exe、換 port 或 Tailscale IP 改變，要檢查規則是否仍符合。目前的啟動腳本只綁定 Tailscale IP，可避免同時開在一般 Wi-Fi／乙太網路位址。

## 3. 交給朋友哪些東西？

請交付這三項：

1. `nightlink-client.zip`。
2. Tailscale 裝置分享邀請（若不在同一個已授權的 tailnet）。
3. 主機的 Tailscale IPv4 與 port，預設為 9000。

可以直接複製以下文字並填好：

```text
請先安裝 Tailscale，登入自己的帳號並接受我的主機分享邀請。
將 nightlink-client.zip 完整解壓縮，再開啟 chat_gui.exe。

聊天室伺服器 IPv4：________________
連接埠：9000
暱稱：自選，不要與在線上的人重複

請先進 lobby 發一句文字，再傳一張小於 1 MiB 的 PNG 測試。
建立新房間後還要按「加入」，我們要在同一房間才能聊天。
```

使用者不需要安裝 CMake、clang、MSYS2、Python，也不需要取得整份原始碼。Tailscale 是另外安裝的網路工具，不包含在壓縮包裡。

## 4. 朋友：安裝與連線

1. 安裝 Tailscale，登入自己的帳號，接受主機分享邀請。
2. 將 `nightlink-client.zip` **全部解壓縮**到可寫資料夾，例如文件或桌面下的新資料夾；不要從壓縮檔內直接執行。
3. 保留 `chat_gui.exe` 旁邊所有 DLL，不要把 exe 單獨搬走。
4. 開啟 `chat_gui.exe`。
5. 暱稱使用 1～32 個英文字母、數字、`_` 或 `-`；暱稱目前不能用中文，聊天內容可以。
6. 主機填對方給你的 Tailscale IPv4，port 填 9000。
7. 按「連線聊天室」。成功後會加入 `lobby`。

第一次執行未簽章程式可能需要核對來源；請確認壓縮包確實來自主機管理者，不要為了使用聊天室而關閉整體安全防護。

## 5. 三個主要功能

### 5.1 傳送與接收訊息

- 在輸入框打字，按「傳送」或 Enter。
- Shift+Enter 換行；輸入法組字期間的 Enter 用於確認字詞。
- 同房間的所有在線成員會收到，包含自己。
- 文字限制為 4096 **bytes**，不等於 4096 個中文字。
- 傳送者自己的訊息也由 server 回傳後顯示；佇列接受不等於收件者已讀。

### 5.2 傳送圖片與檔案

1. 按「傳送檔案」。
2. 選擇不超過 **1 MiB（1,048,576 bytes）**的檔案。
3. 同房間的用戶端接收後，會保存到其 exe 旁的 `downloads`。
4. PNG、JPEG、BMP、GIF 等可解碼圖片會顯示縮圖；GIF 為靜態預覽。
5. 按「下載資料夾」可以找到原始檔案。

下載名稱類似 `received_行程ID_序號.png`，原始檔名仍會顯示於聊天區。沒有有效副檔名時可能使用 `.bin`；它不代表內容遺失，真實圖片即使是 `.bin` 也可能正常預覽。

預覽還受寬高 8192 與總像素 2500 萬的限制。超限、格式不支援或解碼失敗時，下載資訊仍可保留；「檔案接收成功」和「圖片顯示成功」是不同驗收項目。

聊天區最多保留 24 個圖片物件，較舊預覽會被替換為提示，磁碟原檔不會隨之刪除。下載資料夾沒有自動總量清理，請自行整理。

### 5.3 房間系統

- 登入後預設在 `lobby`。
- 輸入新房名後按「建立」，**建立完還要選取並加入**。
- 選取房間按「加入」，或雙擊清單中的房間。
- 每個連線同一時間只在一個房間；換房不需要重新連線。
- 別人建立房間後，可按「更新」重新載入清單。
- 文字與圖片都只轉送給同房間的人。
- 「離開」後仍維持連線，但需重新加入房間才能發文字或檔案。
- 「歷史訊息」取回目前房間最多 100 則文字紀錄，沒有檔案歷史。

房名規則與暱稱相同；目前沒有房間密碼、成員審核或刪除房間功能。任何已登入者知道房名且房間存在，就可加入。伺服器重啟後，新建房間及文字歷史不會保留。

## 6. 每次重開機後

主機管理者：確認 Tailscale 在線 → 雙擊解壓目錄裡的 `start-server.cmd` → 把顯示的 IPv4／port 告訴朋友。

朋友：確認 Tailscale 在線 → 開啟解壓目錄裡的 `chat_gui.exe` → 填主機資訊並登入。

不需要重新編譯。主機關機、睡眠、Tailscale 離線或 server 關閉，都會讓聊天室不可用。一般 GUI 斷線後要重新按連線，沒有完整的自動重連與離線訊息補送。

## 7. 跨電腦驗收表：雙方照著做

**這一步要由兩台不同電腦完成。** 同一電腦連自己的 Tailscale IP 只能驗證本機綁定位址與程式流程，不能證明分享權限、遠端網路和防火牆已正確。

| 步驟 | 操作 | 成功標準 |
|---|---|---|
| 1 | 主機啟動 server；朋友連入 | 兩邊 GUI 皆登入 lobby，暱稱不同 |
| 2 | 主機 GUI 發「主機測試，中文123」 | 朋友收到完整文字 |
| 3 | 朋友回覆「朋友測試，中文456」 | 主機收到完整文字 |
| 4 | 主機傳一張小於 1 MiB 的 PNG | 朋友看見縮圖，downloads 可找到原檔 |
| 5 | 朋友傳另一張 PNG／JPEG | 主機看見縮圖並收到原檔 |
| 6 | Alice 建立並加入 `testroom`；Bob 暫留 lobby | Alice 的新文字與圖片不出現在 Bob 畫面 |
| 7 | Bob 更新清單並加入 `testroom` | 新文字與圖片可雙向收發 |
| 8 | Bob 按歷史訊息 | 能看到該房間先前的文字，不期待補收檔案 |
| 9 | Bob 離開再重新加入 | 離房期間不能發送，重入後恢復 |
| 10 | Bob 中斷連線後重新登入 | 可再次聊天，已釋放的暱稱可重用 |

若要確認附件未被改變，在傳送方原檔與接收方下載檔分別執行 `Get-FileHash -Algorithm SHA256 -LiteralPath '檔案完整路徑'`，比較 Hash 是否完全一致。

## 8. 連不上時的檢查順序

朋友可以用 PowerShell 執行，下方地址要改成主機實際 IPv4：

```powershell
$serverIp = '填入主機的 Tailscale IPv4'
& "$env:ProgramFiles\Tailscale\tailscale.exe" ping $serverIp
Test-NetConnection -ComputerName $serverIp -Port 9000
```

- `tailscale ping` 不通：先檢查登入、分享是否接受、主機是否在線、Tailscale 存取政策。
- Tailscale 可達但 `TcpTestSucceeded` 是 False：檢查 server 是否啟動、是否只綁 localhost、port、防火牆與政策是否允許 TCP 9000。
- TCP 成功但 GUI 登入失敗：檢查暱稱是否重複／不合規；也可能連到錯誤版本的服務。
- 文字成功但收不到對方圖片：確認兩人在同一房間、檔案不超過 1 MiB，並檢查聊天區錯誤提示。
- 下載成功但無縮圖：檢查實際圖片格式與像素尺寸；不要只改副檔名。
- 缺少 DLL：重新完整解壓客戶端包，不要從不明網站單獨下載 DLL。
- server bind 失敗：確認 Tailscale 位址存在，以及是否已經啟動另一份相同 port 的 server。
- 啟動腳本無法讀 Tailscale IP：先在自己的 PowerShell 執行 `tailscale status`；確認服務、登入與帳號操作權限。

普通 ICMP ping 與應用程式 TCP 連線不是同一測試；不要單憑普通 ping 失敗就認定聊天室一定不通。[Windows ping 問題說明](https://tailscale.com/docs/reference/troubleshooting/windows/windows-ping-issues)

本機測試不代表已完成遠端分享，也未自動寄出邀請或更改 Tailscale 存取政策。自動化 RichEdit 測試不是實際用滑鼠完成跨電腦圖片收發的替代證據。

Tailscale 為連線提供私人加密網路；聊天室本身仍是暱稱登記，沒有密碼帳號或 TLS。請只分享給預定使用者。房間名稱不是存取控制。

## 10. 開發者：重建、重測與重新打包

以下指令從 `TCPIP-HW` 目錄執行；一般聊天使用者不需要執行。

```powershell
cmake -S HW1 -B HW1/build -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER=D:/msys2/ucrt64/bin/g++.exe
cmake --build HW1/build -j 4
ctest --test-dir HW1/build --output-on-failure
powershell.exe -NoProfile -ExecutionPolicy Bypass -File HW1/scripts/package.ps1
```

最後一行會產生 `HW1/build/packages/時間戳/`，內含兩份 zip。打包腳本遞迴檢查 MinGW DLL 依賴，複製必要 runtime，附上說明書與 SHA256 清單。每次產生新資料夾，避免把舊的下載檔案或其他資料打入包裡。更改程式後先成功建置與測試，再打包；DLL 來自工具鏈，不會替你編譯程式。

若要重新執行本機 Tailscale 位址測試：

```powershell
$serverIp = (& "$env:ProgramFiles\Tailscale\tailscale.exe" ip -4 | Select-Object -First 1).Trim()
python HW1/tests/remote_smoke.py --host $serverIp --port 19090 --start-server HW1/build/chat_server.exe
```

測試會啟動臨時 server，建立三個用戶，完成檢查後自行停止，不會把它當作長期運作的聊天室。

若朋友電腦另有 Python，可把 `tests/remote_smoke.py` 交給他，對你正在運作的 server 執行：

```powershell
python remote_smoke.py --host 主機的實際IPv4 --port 9000
```

遠端模式**不要加 `--start-server`**。它會在現有 server 新建一間隨機測試房；因為目前沒有刪房功能，該測試房會留到 server 重啟。此測試驗證 TCP 功能與圖片 bytes，GUI 的縮圖顯示仍要照第 7 節確認。

## 11. 搬移後的工作目錄與驗證

後續開發與建置目錄改為 `D:\vcode\TCPIP-HW`，原始碼位於其 `HW1` 子資料夾。請使用此處重新建置的執行檔與 `HW1/build/packages` 內的新壓縮包。

搬移後重新建置及 CTest 兩組測試通過。本機迴路收發、移除 MSYS2 PATH 的打包程式啟動、ZIP 與 SHA256 檢查均通過。重新登入 Tailscale 後，也已用新目錄的打包 server 通過六項收發檢查，以及自動取得 Tailscale IP 的啟動／關閉測試。這些 Tailscale 位址測試仍是同機測試，不取代另一台電腦的人工 GUI 驗收。
